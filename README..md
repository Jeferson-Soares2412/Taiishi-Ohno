O notebook apontou como principais ferramentas e conceitos Lean:

- Just in Time (JIT)
- Kanban
- Jidoka
- Kaizen
- Mapeamento do Fluxo de Valor (VSM)
- Padronização do Trabalho
- Sistema Puxado
- Eliminação dos Desperdícios (Muda)
- Gestão Visual
- Melhoria Contínua
